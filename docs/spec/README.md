# FitNote 명세 문서

> 기준일: 2026-11-05 · 기준 커밋: `main` (코드와 DB 스키마를 읽어 작성)

어떻게 동작하나" 를 개발 문서 형식으로 정리한 것이다. 기능을 바꾸면 해당 문서도 같이 고친다.

| [02 기능 명세서](02-functional-spec.md) | 기능별 동작 규칙, 입력 제한, 예외 처리, 알림 | 개발·QA |

## 읽는 순서

처음이면 01 → 03 → 02 순서가 좋다. 코드를 고치려면 04 의 권한 매트릭스를 먼저 본다.

## 이 문서가 다루지 않는 것

- 디자인 토큰과 컴포넌트 규칙은 디자인 시스템 문서(`CLAUDE.md` 의 링크)가 기준이다
- 배포 절차와 환경변수는 `README.md` 와 `PROGRESS.md` 7-4 에 있다
- 수익 모델과 가격은 아직 정해지지 않아 쓰지 않았다
